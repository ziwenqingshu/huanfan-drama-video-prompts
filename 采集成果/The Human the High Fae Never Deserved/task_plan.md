# 全剧中文译稿校订计划

## 目标

以英文原稿为准，逐集修订现有中文译稿，保证情节、对白、动作和信息完整准确；交付一份无索引的 Markdown 中文剧本，保留两份 PDF 原件。

## 阶段

1. [x] 确认文件、页数、集数、场景数量及用户交付约定。
2. [x] 提取并整理原稿/译稿结构，建立人物与世界观术语表。
3. [x] 逐段对照校订 1–67 集，优先修正错译、漏译、说话人错位和动作偏差。
4. [x] 全文复核：集/场顺序、对白轮次、数字、人物名、术语、遗漏和重复（67 集、114 场，成稿无残留英文；抽查关键错译与版式）。
5. [x] 保存并检查最终 Markdown，汇报剩余不确定项。
